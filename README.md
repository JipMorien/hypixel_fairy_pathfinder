# Fairy Pathfinder

Client-side Fabric mod for Hypixel SkyBlock (Minecraft 26.1.x) that draws a walkable path
to the nearest Fairy Soul you haven't found yet, including through caves.

Display only: the mod never moves, clicks or acts for the player.

## Development
- Java 25, IntelliJ IDEA 2025.3+
- Open the folder in IntelliJ, let Gradle sync, then run the `Minecraft Client` run config.
